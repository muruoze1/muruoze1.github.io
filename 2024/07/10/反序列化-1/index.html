反序列化

发表于2024-07-10|更新于2024-07-10
|阅读量:

简述

反序列化是一种将序列化对象还原成 PHP 对象的过程。通过序列化对象，可以将其存储到文件或数据库中，或者通过网络在不同的 PHP 应用程序之间传输数据。因此，反序列化操作通常与数据持久化和远程过程调用 (RPC) 相关。

在 PHP 中，可以通过 unserialize() 函数进行反序列化操作。该函数将接受一个字符串参数，该字符串包含序列化后的对象数据，然后返回已解压的 PHP 对象。

说白了；序列化就是将对象序列化成字符串，以便快速访问

反序列化就是对已序列化的内容，还原成php对象
类与对象

这里再简单提一下类与对象，类是一种自定义的数据类型，用于定义对象的属性（数据）和方法（行为）

class Car {
    public $brand;
    public $model;
    
    public function __construct($brand, $model) {
        $this->brand = $brand;
        $this->model = $model;
    }
    
    public function startEngine() {
        echo "Starting the $this->brand $this->model engine.";
    }
}
 
$car = new Car("Toyota", "Camry");
$car->startEngine();

看一段简单的代码，这里我们看到，在类Car中，有两个对象brand,model ，同时应用了_construct魔术方法，它是构造函数，是一个在对象被创建时自动调用的方法，用于执行一些初始化操作。（我们看到下文创建了对象Car并赋值给变量car，因此此魔术方法是能够触发的），所以，当代码运行后，我们会初始化对象Car,并将其中的属性brand,model分别赋值（$this->brand=$brand表示访问对象Car中的brand属性并赋值）

接下来我们看到，它定义了一个函数startEngine，它将brand 和 model的值输入到字符串中，并通过echo输出了一句话。这是一个关于类，对象，方法等的一个小实例
反序列化漏洞与实战

PHP 中的反序列化漏洞是指在反序列化过程中，未正确验证和过滤输入数据，导致攻击者可以构造恶意的序列化数据进行利用的安全漏洞。

简单来说，在进行反序列化后，我们可以利用魔术方法等，找到一条利用链，传递一段合适的字符串完成攻击操作

序列化后，对象变为字符串，形式大致如下

O:4:”Car”:2:{s:5:”brand”;s:6:”Toyota”;s:5:”model”;s:5:”Camry”;}

其中O代表对象，后面的s代表字符串类型，这样一段字符串包含了对象的属性的一些简单信息，我们通过传入类似的字符串或许可以达成我们的目的

    {
        $this->start = $start;

    {
        $this->start->helloworld();

class springboard

    public $middle;

        echo $this->middle->hs;

class evil
{
    public $end;

    {
        $this->end = $end;

        eval($this->end);
    }

显然利用点是eval,想办法让eval执行cat /flag,我们满足get,也就是需要访问evil不存在的属性，我们找到call，call的触发条件是调用不存在的方法，再找到destruct,触发它后会调用方法hello world()

利用链：evil::__get()<–springboard::__call()<–entrance::__destruct()

这题是寻找利用链，一步一步达到最终的结果，首先我们来找利用点，应该是Modifier类中的include()函数，我们要想办法令value等于flag.php，并利用魔术方法一步一步来到include()的触发

思路：

序列化时自动触发wakeup,创造一个对象Show，由于preg_match,触发_tostring

触发Show类的_tostring后访问Test类不存在的对象，从而触发Test类的_get

_get触发后让p为Modifier对象，使Modifier作为函数被调用而触发_invoke（）

常见魔术方法总结

__construct(): 在创建对象时自动调用。
 
__destruct(): 在销毁对象时自动调用。
 
__call(): 当调用一个不存在的方法时自动调用。
 
__callStatic(): 当调用一个不存在的静态方法时自动调用。
 
__get(): 当读取一个不存在的属性时自动调用。
 
__set(): 当设置一个不存在的属性时自动调用。
 
__isset(): 在使用isset()或empty()函数判断一个不存在的属性时自动调用。
 
__unset(): 在使用unset()函数删除一个不存在的属性时自动调用。
 
__sleep(): 在进行序列化操作时自动调用，在返回值中可以指定需要序列化的属性。
 
__wakeup(): 在反序列化操作时自动调用。
 
__toString(): 在一个对象被当作一个字符串时自动调用，例如echo $obj。
 
__invoke(): 当一个对象被当作一个函数时自动调用，例如$obj()。
